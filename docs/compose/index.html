Overview Porter–Duff Mathematical Lighting HSL & Color Arguments

This page describes the image composition methods that define how two images are merged together during operations combining a 'source' (overlay) image with a 'destination' (background) image[cite: 2]. For the Command Line API, the method is normally selected with the -compose setting, and applied by operators such as -composite, -layers, -flatten, -mosaic, -draw, and others[cite: 2].

Most alpha-blending operators and lighting modes follow the W3C SVG Compositing Specification, extending SVG 1.1 and 1.2 with full Porter–Duff alpha operators[cite: 2]. ImageMagick implements identical mathematical results to SVG, PDF, and modern graphics libraries[cite: 2].

Composition terminology uses abstract values like QuantumRange and opacity ranging from opaque to transparent[cite: 2]. Method names are case-insensitive and allow _ or - separators (e.g., Dst-Over equals dstover)[cite: 2].

Porter–Duff Alpha Composition Methods

The following twelve classical Porter–Duff operators defined by the SVG 1.2 standard merge two images purely according to transparency[cite: 2].

Method Description
clear Both color and alpha of the destination are cleared. Neither source nor destination is used as input (except meta-data). Result is fully transparent[cite: 2].
src The source is copied to the destination, completely replacing it. Un-overlaid areas are cleared to transparency[cite: 2].
dst The destination is left untouched. Source image is ignored (no-op for color data, useful for testing)[cite: 2].
src-over Source composited over destination. This is the default alpha-blending method when unspecified[cite: 2].
dst-over Destination composited over source. Places source under destination; ideal for backgrounds or drop shadows[cite: 2].
src-in Part of source inside destination shape replaces destination. Everything outside is cleared[cite: 2].
dst-in Part of destination inside source shape replaces destination. Convenient for alpha masks[cite: 2].
src-out Part of source outside destination shape replaces destination. Overlapping region cleared[cite: 2].
dst-out Part of destination outside source shape replaces destination ("punched out" hole)[cite: 2].
src-atop Part of source inside destination shape is composited onto destination, keeping destination shape/alpha[cite: 2].
dst-atop Part of destination inside source shape replaces destination. Result keeps source shape and destination colors[cite: 2].
xor Combines parts of source and destination outside their overlap. Overlapping area is cleared[cite: 2].

Shorthand notes: Src- prefixes can be omitted (e.g., Over, In, Out, ATop)[cite: 2]. Un-overlaid clearing behavior for Clear, Src, Src-In, Dst-In, Src-Out, and Dst-ATop can be disabled via -define compose:outside-overlay=false[cite: 2].

overlay-rose.sh 
$ magick rose: label.png -gravity center -compose Over -composite result.png
drop-shadow.sh 
$ magick label_white.png label_black.png -geometry +5+5 -compose Dst-Over -composite shadow.png

Mathematical Composition Methods

These methods combine color channels using arithmetic or comparison formulas rather than transparency alone[cite: 2]. Includes SVG 1.2 separable blend modes like Multiply, Screen, Darken, Lighten, Difference, and Exclusion[cite: 2].

Method Description
multiply Source multiplied by destination. Result is at least as dark as inputs. Black produces black; white leaves color unchanged[cite: 2].
divide Divides pixel values of one input image by another channel by channel for normalization or contrast[cite: 2].
screen Complements multiplied, then complemented again. Result is at least as light as inputs (mathematical opposite of multiply)[cite: 2].
bumpmap Source intensity multiplied with destination color using single luminance to shade destination (great for embossed textures)[cite: 2].
divide-dst True mathematical division of destination by source (Dc / Sc). Equal colors yield white (1.0). Efficient built-in background removal[cite: 2].
divide-src Reverse of divide-dst: divides source by destination (Sc / Dc)[cite: 2].
plus Source added to destination with alpha channels added. Exceeding QuantumRange is clamped to white[cite: 2].
add
(modulus-add)		 Like plus, but exceeding QuantumRange wraps around using modulus arithmetic. Transparent areas remain transparent[cite: 2].
minus
(minus-dst)		 Subtracts source color from destination (Dc - Sc) with negative results clamped to black[cite: 2].
minus-src Reverse of minus-dst: subtracts destination from source (Sc - Dc)[cite: 2].
subtract
(modulus-subtract)		 Subtracts source from destination, wrapping negative results with modulus arithmetic rather than clamping[cite: 2].
difference Absolute difference between colors. White inverts destination; black produces no change; identical colors produce black[cite: 2].
exclusion Similar to difference but lower in contrast[cite: 2].
darken Selects darker of destination and source channel-by-channel[cite: 2].
lighten Selects lighter of destination and source channel-by-channel[cite: 2].
darken-intensity Compares overall luminance rather than channels; keeps whole pixel that is darker, preserving hue[cite: 2].
lighten-intensity Compares overall luminance; keeps whole pixel that is lighter[cite: 2].
negate Opposite of difference; intermediate colors become brighter instead of darker[cite: 2].
reflect Related to color-dodge for adding shiny objects or bright light zones[cite: 2].
freeze Inverts base and blend colors, applies reflect, and inverts result to deepen shadows[cite: 2].
stamp Similar to average mode for relief/bump textures while retaining mid-tones[cite: 2].
interpolate Combines multiply and screen using smooth cosine interpolation (gentle S-curve)[cite: 2].

Use -define compose:sync=false to apply math composition on individual channel bases (including alpha) without alpha composition interference[cite: 2].

flatten-lighting.sh 
$ magick scan.png \( +clone -blur 0x20 \) -compose Divide_Src -composite flattened.png

Lighting Composition Methods

Light, dodge, and burn blend modes standard to SVG 1.2 and popular image editors[cite: 2].

Method Description
linear-dodge Equivalent to plus (adds channels without adding alpha), using normal Over alpha blending[cite: 2].
linear-burn Additive counterpart to screen; subtracts one (full white) from result, darkening image[cite: 2].
color-dodge Brightens destination to reflect source by dividing destination by inverse source[cite: 2].
color-burn Darkens destination to reflect source (inverse of color-dodge)[cite: 2].
overlay Multiplies or screens colors based on destination color, preserving highlights and shadows[cite: 2].
hard-light Multiplies or screens based on source color value (<0.5 darkens like multiply, >0.5 lightens like screen)[cite: 2].
hard-mix Adds source and destination values then thresholds result to pure black or white per channel[cite: 2].
linear-light Like hard-light, but using linear-dodge and linear-burn for strong contrast impact[cite: 2].
soft-burn Combination of color-burn and inverse color-dodge; lightens base slightly while burning dark blend colors[cite: 2].
soft-dodge Combination of color-dodge and inverse color-burn; darkens base slightly while dodging bright blend colors[cite: 2].
soft-light SVG 1.2 soft-light mode; darkens or lightens depending on source value (<0.5 darkens, >0.5 lightens) without pure black/white[cite: 2].
pegtop-light Computed with a continuous mathematical formula to avoid soft-light's discontinuity at 0.5[cite: 2].
vivid-light Modified linear-light designed to preserve strong primary and secondary colors[cite: 2].
pin-light Simulates pinhole light source using sharp linear shadings[cite: 2].
blend-texture.sh 
$ magick photo.png texture.png -compose Soft-Light -composite result.png

Channel-Copying & Color (HSL) Methods

Transfer individual channels or HSL components (hue, saturation, luminosity) without arithmetical blending[cite: 2].

Method Description
copy Equivalent to Src composition without clearing un-overlaid destination parts[cite: 2].
copy-<channel> Copies specified channel (Red, Green, Blue, Cyan, Magenta, Yellow, Black, Alpha) from source to destination[cite: 2].
hue Replaces destination hue with source hue while keeping saturation and luminosity[cite: 2].
saturate Replaces destination saturation with source saturation while keeping hue and luminosity[cite: 2].
luminize Replaces destination luminosity with source luminosity while keeping hue and saturation[cite: 2].
colorize Replaces destination hue and saturation with source while keeping luminosity (ideal for tinting grayscale images)[cite: 2].
colorize-portrait.sh 
$ magick portrait.png xc:steelblue -compose Colorize -composite tinted.png

Other Special-Purpose Methods

Method Description
no True no-op indicating no composition should be performed[cite: 2].
change-mask Replaces destination pixels similar to source pixel (within -fuzz factor) with transparency[cite: 2].
stereo Creates stereo anaglyph taking red channel from source and green/blue from destination[cite: 2].

Composition Methods That Take Arguments

These methods require extra numerical arguments, passed via -define compose:args=... in the magick command[cite: 2].

compose-args.sh 
$ magick ... -compose blend -define compose:args=50,50 -composite ...
Method Description
dissolve Arguments: src_percent[x
dst_percent]. Dissolves source image by percentage before overlaying[cite: 2].
blend Arguments: src_percent[x
dst_percent]. Averages images together according to percentages and transparency[cite: 2].
mathematics Arguments: A, B, C, D. Merges via formula A*Sc*Dc + B*Sc + C*Dc + D[cite: 2].
modulate Arguments: brightness[x
saturation]. Takes grayscale image/mask to modify destination brightness/saturation[cite: 2].
displace Arguments: X-scale[x
Y-scale][!][%]. Uses overlay as relative displacement map (lens distortion)[cite: 2].
distort Arguments: X-scale[x
Y-scale[+
X-center+
Y-center]]][!][%]. Uses absolute coordinates relative to overlay center[cite: 2].
blur Arguments:
Width[xHeight[+Angle][+Angle2]]. Variable-blur mapping composition via EWA ellipse[cite: 2].
seamless-blend Arguments: max-iterationsx
distortion. Seamlessly inserts overlay onto background using a mask (best with HDRI)[cite: 2].
saliency-blend Arguments: max-iterationsx
distortion. Merges images based on which has most detail at each pixel (requires mask)[cite: 2].

To print a complete list of all available compose operators supported by your specific build, run magick -list compose[cite: 2].
