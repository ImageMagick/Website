The FX special effects image operator applies mathematical expressions to each pixel channel of an image. The FX expression language provides a flexible mechanism for fine-grained pixel-level transformations, analysis, and custom procedural generation.

Procedural Generation

Create procedural canvases, mathematical gradients, colormaps, and fractal sets from equations.

Geometric Distortion

Translate, flip, mirror, rotate, scale, shear, and warp images using custom coordinate functions.

Compositing & Channel Routing

Move color channels between images, convolve pixel neighborhoods, and merge multiple inputs seamlessly.

Sequence Processing Note: The operator loops through all pixels and channels, returning a modified copy of the first image in the sequence (u). Other images in the sequence serve as reference data unless +fx is used to process every image individually.

Examples & Scripting Workflows

1. Simple Channel Modification (Canvas Color Swap)

Convert a black canvas to navy blue by assigning a fixed fractional value to the blue channel:

$ magick -size 64x64 canvas:black -channel blue -fx "1/2" fx_navy.png

3. Custom Variables & Radial Gradients

Assign intermediate variable calculations (Xi, Yj) to construct mathematical gradients:

$ magick -size 70x70 canvas: -fx "Xi=i-w/2; Yj=j-h/2; 1.2*(0.5-hypot(Xi,Yj)/70.0)+0.5" radial-gradient.png
Generated Pattern

Inject custom statistical Gaussian noise into an image pipeline:

$ magick photo.jpg -fx 'iso=32; rone=rand(); rtwo=rand(); \
  myn=sqrt(-2*ln(rone))*cos(2*Pi*rtwo); myntwo=sqrt(-2*ln(rtwo))* \
  cos(2*Pi*rone); pnoise=sqrt(p)*myn*sqrt(iso)* \
  channel(4.28,3.86,6.68)/255; max(0,p+pnoise)' noisy.png

Leverage iterative for() loops to map complex polynomial fractal calculations into color lookup tables (CLUT):

$ magick -size 400x400 xc:gray -fx " \
  Xi=2.4*i/w-1.2; \
  Yj=2.4*j/h-1.2; \
  for (pixel=0.0, (hypot(Xi,Yj) < 2.0) && (pixel < 1.0), \
    delta=Xi^2-Yj^2; \
    Yj=2.0*Xi*Yj+0.2; \
    Xi=delta+0.4; \
    pixel+=0.00390625 \
  ); \
  pixel == 1.0 ? 0.0 : pixel" \
  \( -size 1x1 xc:white xc:red xc:orange xc:yellow xc:green1 xc:cyan xc:blue \
     xc:blueviolet xc:white -reverse +append -filter Cubic -resize 1024x1! \) \
  -clut -rotate -90 julia-set.png

Use the debug() statement inside FX loops to calculate math output directly to standard output:

$ magick xc:gray -fx " \

The Anatomy of an FX Expression

s, t, nCurrent image reference (s), image sequence index (t), total image count (n).
i, j, pCurrent column offset (i), row offset (j), target pixel channel accessor (p).
w, h, zCurrent image width (w), height (h), channel depth (z).
r, g, b, a, oRed, green, blue, alpha, and opacity values of the target pixel.

Operator Precedence
  • Precedence 1 (Power): ^
  • Precedence 2 (Unary/Multiplicative): -, *, /, %
  • Precedence 3 (Additive/Shift): +, -, <<, >>
  • Precedence 4 (Relational): <, <=, >, >=, ==, !=
  • Precedence 5 (Bitwise/Logical): &, |, ~, &&, ||, !
  • Precedence 6 (Conditional): ?: (Ternary operator)
  • Precedence 7 (Assignment): =, +=, -=, *=, /=, %=
Control Structures & Conditionals
Ternary Operator (condition ? expr1 : expr2)
Evaluates and returns expr1 if condition is non-zero (true); otherwise returns expr2.
Example: u > 0.5 ? 1.0 : 0.0
if(condition, then_statement, else_statement)
Conditional execution function. Evaluates then_statement if condition holds true, or the optional else_statement if false.
Example: if(u.r > 0.5, 1, 0)
while(condition, statement)
Repeatedly executes statement as long as condition evaluates to non-zero (true).
Example: while(x < 10, x+=1)
Syntax & Semantics Rules
  • Symbols and built-in identifiers are case insensitive.
  • Only one ternary conditional (x ? y : z) is permitted per individual expression statement.
  • Single-character variable names are strictly reserved for built-ins. Use multi-character names for custom variables (e.g. Xi, iso).
  • Unary operators take a lower priority than binary operators. For instance, -3^2 evaluates as -(3^2) = -9. Always use parentheses ((-3)^2 = 9) to explicitly indicate order.
  • Implicit multiplication is not performed over fractions; 1/2x is interpreted as (1/2)x. Write 1/(2x) explicitly when required.

Source Images & Pixel Addressing

Image Sequence Indexes

Use index qualifiers on image references to query other images in the current sequence stack. Zero is the first image; negative indexes count backward from the end.

  • u[0] First image
  • u[2] Third image
  • u[-1] Last image in list
  • u[t] Current image (s)
$ magick img1.jpg img2.jpg img3.jpg -fx "(u+u[2])/2" out.jpg
Pixel & Neighborhood Access

All color values are normalized in the range 0.0 to 1.0. Use relative indexing (brackets) or absolute coordinates (braces) with p:

Relative Offset:
p[-1,-1].r
Red channel of the pixel diagonally top-left from current location
Absolute Offset:
p{12,34}.b
Blue channel value at column 12, row 34
Format Escapes & String Evaluations

Instead of modifying pixels directly on an image canvas, FX formulas can be embedded into string escapes for metadata queries or dynamic settings:

%[fx:] Value Escape

Evaluated once per image in sequence. Returns numerical computation result directly into format attributes.

$ magick rose: -format '%[fx:w*h]' info:
%[pixel:] Color Escape

Evaluates formula across color channels and automatically outputs a standardized CSS color or hex string.

$ magick rose: -format '%[pixel:p{0,0}]' info:
