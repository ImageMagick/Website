cription: "Reference guide for ImageMagick warning, error, and fatal error codes across various operational domains." ---

ImageMagick returns a status of 0 whenever a command or algorithm successfully completes without complaint[cite: 11]. A warning code is typically just a notice that something unusual occurred, but the command or algorithm still completed and most likely the results are still usable[cite: 11]. An error means the command or algorithm could not complete as expected and any results are unreliable[cite: 11]. A fatal error means the command or algorithm could not complete, the process exits prematurely, and no results are returned[cite: 11].
