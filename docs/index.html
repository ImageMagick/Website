ImageMagick® is a free, open-source software suite for editing, processing, and converting digital images. It supports over 200 format variants, including modern standards like JPEG, PNG, GIF, TIFF, WebP, AVIF, and Ultra HDR.

High Performance Gigapixel-scale images, processed in parallel.
CLI & Automation Scripting-first design for mass batch jobs.
Extensive APIs Bindings for C, C++, Python, .NET, Node.js.
