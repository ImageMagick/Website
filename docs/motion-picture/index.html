DPX (SMPTE 268M-2003) is widely used in the motion picture and visual effects industry, leveraging extensive header information and the flexibility to handle high dynamic range and logarithmic color values across various bit depths using RGB or YCbCr pixel descriptions. It is based on, and largely supersedes, Kodak's Cineon format[cite: 15].

Typical workflows involve scanning film for post-production. Each frame is stored as an individual DPX file ranging from 2K (2048px wide) up to 8K (8192px wide for IMAX) at 8 to 64 bits per color component[cite: 15]. Sequences are processed via compositing software before being recorded back to tape or projected onto film[cite: 15].

High Dynamic Range & Metadata

The header can contain production-specific film or television data. Television headers can store SMPTE timecodes to allow seamless replacement of shots exported as DPX sequences[cite: 15], while film headers preserve reel information and camera settings[cite: 15]. These details follow the images throughout post-production pipelines[cite: 15].

Logarithmic Color Format

Color values are often stored logarithmically to mirror the density of color information in film emulsion. Unaltered logarithmic files appear low-contrast and require a look-up table (LUT) for cinematic projection[cite: 15]. Beyond linearizing the image and adjusting gamma, LUTs define black and white points[cite: 15].

For 10-bit logarithmic images ranging from 0 to 1023, black and white points are typically set to 95 and 685, respectively. This stores color values lighter than pure white and darker than pure black, preserving extra highlight and shadow data for downstream grading[cite: 15].

Command-Line Inspection & Modification

Inspect all associated properties using verbose output:

$ magick identify -verbose bluebells.dpx

Query a specific property format:

$ magick identify -format "%[dpx:television.time.code]" bluebells.dpx

Modify and write a property value:

$ magick bluebells.dpx -define dpx:television.time.code=10:00:02:15 bluebells-001.dpx

DPX Settings

Use -set to specify gamma, film gamma, or reference black and white points: 

-set gamma 1.7
-set film-gamma 0.6
-set reference-black 95
-set reference-white 685
-set profile dpx:user.data
