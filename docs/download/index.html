Linux Binary macOS Binary Windows Binary

You can install ImageMagick from source, or grab a ready-to-run package below. Review recent changes or check our global mirrors.

Some binary versions are labeled by their architecture, color precision, and build type:

  • x64 is for 64-bit Intel or AMD processors, arm64 for 64-bit ARM processors, and x86 for 32-bit systems.
  • Q8 and Q16 store each color component with 8 or 16 bits, respectively. Q16 can retain more precision and uses more memory.
  • HDRI enables floating-point pixels that can represent values beyond the usual range, useful for high dynamic-range imaging.
  • Dynamic builds use shared libraries; static builds link ImageMagick libraries into the executable.
It is strongly recommended to establish a security policy suitable for your local environment before utilizing ImageMagick.

Linux Binary Release

We provide AppImage as the official portable binary format. For specialized configurations, build from source.

{% include download-link.html variant="gcc-x86_64.AppImage" %}
{% include download-link.html variant="clang-x86_64.AppImage" %}

Complete portable application, zero installation required. Verify using its {% include provenance-link.html %}:

$ mv ImageMagick-*-x86_64.AppImage magick && chmod +x magick && ./magick rose: rose.png

Add a custom security policy and review the policy:

$ cp policy.xml ~/.config/ImageMagick && ./magick -list policy

macOS Binary Release

We recommend using Homebrew for macOS environments.

Standard Installation
$ brew install imagemagick
$ brew install ghostscript
Full Suite (Optional codecs: SVG, RAW, OpenMP)
$ brew install imagemagick-full
Note: imagemagick-full is keg-only and not automatically linked to your system PATH.

Command-Line Package Managers

Quickly install via winget, scoop, or chocolatey:

$ winget install ImageMagick.Q16-HDRI
$ scoop install main/imagemagick
$ choco install imagemagick
Verify Installation
$ magick logo: logo.gif
$ magick identify logo.gif

Missing dependencies? You may need the Visual C++ Redistributable Package.
