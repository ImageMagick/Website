PerlMagick is an object-oriented Perl interface to ImageMagick. Use the module to read, manipulate, or write an image or image sequence from within a Perl script, making it well suited for Web CGI scripts. ImageMagick 6.5.5 or above and Perl version 5.005_02 or greater are required for PerlMagick to build properly.

Several useful scripts demonstrate the capabilities of PerlMagick: perform Web-based image manipulation and conversion with MagickStudio, generate plant images using mathematical constructs with L-systems, or browse collections of thumbnail images with the WebMagick Image Navigator.

You can also try PerlMagick directly in your Web browser at ImageMagick Studio, or explore examples of select PerlMagick functions.

Installation

UNIX

Check if PerlMagick is available from your system package repository. For example, on CentOS systems, install it with:

yum install ImageMagick-perl

Otherwise, install PerlMagick from the ImageMagick source distribution. Download the latest {% include download-link.html variant="source" label="source" %} release and unpack it:

tar xvzf ImageMagick.tar.gz

Configure and compile ImageMagick with Perl support:

cd ImageMagick-{{ site.magick.version }}
./configure -with-perl
make

Once compiled without errors, install it (administrator privileges required) and update the dynamic linker run-time bindings:

sudo make install
sudo ldconfig /usr/local/lib

Verify that PerlMagick is properly installed:

perl -MImage::Magick -le 'print Image::Magick->QuantumDepth'

You are now ready to use PerlMagick to convert, compose, or edit your images.

Windows XP / Windows 2000

ImageMagick must already be installed along with the ImageMagick source distribution for Windows 2000 and nmake from the Visual C++ or J++ development environment. Copy \bin\IMagick.dll and \bin\X11.dll to a directory in your dynamic load path such as c:\perl\site\5.00502, then build and install:

cd PerlMagick
perl Makefile.nt
nmake
nmake install
Running the Regression Tests

To verify a correct installation, run the test suite (use nmake test under Windows):

make test

You can also use the prove utility to run an individual test from the build folder, or build the included demonstration scripts:

prove --blib blib -I `pwd` -bv ./t/read.t

cd demo
make

You are now ready to utilize PerlMagick methods within your Perl scripts.

Overview

Any script that uses PerlMagick methods must first import the Image::Magick namespace and instantiate an image object:

use Image::Magick;

$image = Image::Magick->new;

PerlMagick is quantum aware. You can request a specific quantum depth when instantiating an image object:

use Image::Magick::Q16;

$image = Image::Magick::Q16->new;

The new() method accepts the same parameters as SetAttribute. For example:

$image = Image::Magick->new(size=>'384x256');

Typical workflows involve reading an image or image sequence, manipulating it, and displaying or writing the result. Input and output methods are covered in Read or Write an Image, while Set an Image Attribute and Get an Image Attribute control and inspect image properties. Refer to Manipulate an Image for image transformations, Create an Image Montage for tiling thumbnails onto a background, and Miscellaneous Methods for additional utilities.

Because each image in a sequence is stored in virtual memory—potentially consuming mebibytes of RAM—you should destroy PerlMagick objects when finished to free memory for other Perl operations. Use undef to destroy the entire object:

undef $image;

To delete all images while retaining the Image::Magick object, use:

@$image = ();

To delete a single image from a multi-image sequence, use:

undef $image->[$x];

Some PerlMagick methods rely on external delegates such as Ghostscript, which may require adding their directory to your PATH environment variable (for example, in Linux):

$ENV{PATH} = '/../bin:/usr/bin:/usr/local/bin';

Example Script

Here is a basic example script to get you started:

#!/usr/local/bin/perl
use Image::Magick;

my($image, $x);

$image = Image::Magick->new;
$x = $image->Read('girl.png', 'logo.png', 'rose.png');
warn "$x" if "$x";

$x = $image->Crop(geometry=>'100x100+100+100');
warn "$x" if "$x";

$x = $image->Write('x.png');
warn "$x" if "$x";

This script reads three images, crops them, and writes the resulting sequence. You can also access and manipulate individual frames within a sequence:

#!/usr/local/bin/perl
use Image::Magick;

my($image, $p, $q);

$image = new Image::Magick;
$image->Read('x1.png');
$image->Read('j*.jpg');
$image->Read('k.miff[1, 5, 3]');
$image->Contrast();
for ($x = 0; $image->[$x]; $x++)
{
  $image->[$x]->Frame('100x200') if $image->[$x]->Get('magick') eq 'GIF';
  undef $image->[$x] if $image->[$x]->Get('columns') < 100;
}
$p = $image->[1];
$p->Draw(stroke=>'red', primitive=>'rectangle', points=>'20,20 100,100');
$q = $p->Montage();
undef $image;
$q->Write('x.miff');

To create a 100×100 pixel white canvas with a red pixel in the center:

$image = Image::Magick->new;
$image->Set(size=>'100x100');
$image->ReadImage('canvas:white');
$image->Set('pixel[49,49]'=>'red');

To reduce the red component intensity at (1,1) by half:

@pixels = $image->GetPixel(x=>1,y=>1);
$pixels[0]*=0.5;
$image->SetPixel(x=>1,y=>1,color=>\@pixels);

To convert a color image to grayscale:

$image->Quantize(colorspace=>'gray');

To annotate an image with a Taipei TrueType font:

$text = 'Works like magick!';
$image->Annotate(font=>'kai.ttf', pointsize=>40, fill=>'green', text=>$text);

To extract all pixel intensities from an image and write them to STDOUT:

@pixels = $image->GetPixels(map=>'I', height=>$height, width=>$width, normalize=>true);
binmode STDOUT;
print pack('B*',join('',@pixels));

Other useful operations on PerlMagick image sequences include:

$i = $#$p+1;      # return the number of images associated with object p
push(@$q, @$p);  # push the images from object p onto object q
@$p = ();        # delete the images but not the object p
$p->Convolve([1, 2, 1, 2, 4, 2, 1, 2, 1]);   # 3x3 Gaussian kernel

Read or Write an Image

Use the methods listed below to read, write, or display an image or image sequence:

Read or Write Methods
Method Parameters Return Value Description
Read one or more filenames the number of images read read an image or image sequence
Write filename the number of images written write an image or image sequence
Display server name the number of images displayed display the image or image sequence to an X server
Animate server name the number of images animated animate image sequence to an X server

For convenience, Write(), Display(), and Animate() accept any parameter supported by SetAttribute. For example:

$image->Write(filename=>'image.png', compression=>'None');

Use - as the filename to Read() from standard input or Write() to standard output:

binmode STDOUT;
$image->Write('png:-');

To read a GIF image from a Perl filehandle:

$image = Image::Magick->new;
open(IMAGE, 'image.gif');
$image->Read(file=>\*IMAGE);
close(IMAGE);

To write a PNG image to a Perl filehandle:

$filename = "image.png";
open(IMAGE, ">$filename");
$image->Write(file=>\*IMAGE, filename=>$filename);
close(IMAGE);

Note that reading from or writing to a Perl filehandle may fail under Windows due to mismatched C-runtime library versions between ImageMagick and ActiveState Perl distributions, or if a DLL is linked with /MT. See Potential Errors Passing CRT Objects Across DLL Boundaries for details.

If %0Nd, %0No, or %0Nx appears in the filename, it is interpreted as a printf format specification and replaced with the decimal, octal, or hexadecimal scene number. For example, image%03d.miff writes files image000.miff, image001.miff, etc.

You can optionally append Image to any method name (for example, ReadImage() is an alias for Read()).

Compare an Image to its Reconstruction

Mathematically and visually annotate the difference between an image and its reconstruction using the Compare() method:

Compare Parameters
Parameter Values Description
channel double select image channels, the default is all channels except alpha.
fuzz double colors within this distance are considered equal
image image-reference the image reconstruction
metric AE, MAE, MEPP, MSE, PAE, PSNR, RMSE measure differences between images with this metric

In this example, we compare the ImageMagick logo to a sharpened reconstruction:

use Image::Magick;

$logo = Image::Magick->New();
$logo->Read('logo:');
$sharp = Image::Magick->New();
$sharp->Read('logo:');
$sharp->Sharpen('0x1');
$difference = $logo->Compare(image=>$sharp, metric=>'rmse');
print $difference->Get('error'), "\n";
$difference->Display();

In addition to reporting a root mean squared error of around 0.024, a difference image is displayed to visually highlight variations between the two images.

Working with Blobs

A blob contains binary data representing an image directly in memory rather than on disk. PerlMagick supports blobs across all supported image formats and provides methods to convert between images and blobs:

Blob Methods
Method Parameters Return Value Description
ImageToBlob any image attribute an array of image data in the respective image format convert an image or image sequence to an array of blobs
BlobToImage one or more blobs the number of blobs converted to an image convert one or more blobs to an image

ImageToBlob() returns image data in its respective format, which you can print, store in an ODBC database, write to a file, or pipe to a display program:

@blobs = $image->ImageToBlob();
open(DISPLAY, "| display -") || die;
binmode DISPLAY;
print DISPLAY $blobs[0];
close DISPLAY;

BlobToImage() populates an image object from one or more supplied blobs:

@blob = $db->GetImage();
$image = Image::Magick->new(magick=>'jpg');
$image->BlobToImage(@blob);

Miscellaneous Methods

The Append() method joins a set of images left-to-right by default, or top-to-bottom when stack is set to True:

$p = $image->Append(stack=>{true,false});

The Clone() method copies all images from object $p to $q for single or multi-image sequences:

$q = $p->Clone();

Coalesce() composites an animation sequence (such as GIF, MIFF, or MNG) while respecting page offsets and disposal methods, returning a new sequence where every frame matches the virtual canvas size of the first image:

$q = $p->Coalesce();

The ComplexImages() method performs complex mathematics across an image sequence:

$p = $image->ComplexImages('conjugate');

The EvaluateImages() method applies an arithmetic, logical, or relational expression across a set of images (for example, averaging all frames):

$p = $image->EvaluateImages('mean');

The Features() method returns Haralick texture features for each channel in four directions (horizontal, vertical, and left/right diagonals) at the specified distance—including angular second momentum, contrast, correlation, variance, inverse difference moment, sum/difference averages, variances, entropies, and information measures of correlation—ordered as RGB, CMYK, RGBA, or CMYKA:

@features = $image->Features(1);

The Flatten() method composes each subsequent image in a sequence over the first image and returns a single flattened result:

$p = $images->Flatten(background=>'none');
$p->Write('flatten.png');

The Fx() method applies a mathematical expression to an image or sequence (for example, replacing the red channel with the average of green and blue). See FX, The Special Effects Image Operator for full syntax details:

$p = $image->Fx(expression=>'(g+b)/2.0', channel=>'red');
$p->Write('fx.miff');

Histogram() returns the unique colors in the image along with their pixel counts as an array of red, green, blue, opacity, and count values.

The Morph() method linearly interpolates both pixel values and dimensions between consecutive images to create a smooth metamorphosis (default is 1 in-between frame):

$p = $image->Morph(frames=>integer);

Mosaic() creates an image mosaic from an image sequence.

Mogrify() provides a single entry point for any method in Manipulate an Image, taking the method name followed by its parameters. These two calls are equivalent:

$image->Crop('340x256+0+0');
$image->Mogrify('crop', '340x256+0+0');

MogrifyRegion() works like Mogrify() but restricts the transformation to a specified geometry region (for example, brightening a 100×100 region at offset (40, 50)):

$image->MogrifyRegion('100x100+40+50', 'modulate', brightness=>50);

PerceptualHash() computes perceptual hashes that map visually identical images to identical or closely matching values—useful for image retrieval, authentication, indexing, copy detection, and watermarking. Seven hash values are returned per channel across both sRGB and HCLp colorspaces (42 values total for an sRGB image):

@phash = $image->PerceptualHash();

Ping() efficiently queries image metadata—returning width, height, file size in bytes, and format—without decoding the full image into memory. It accepts multiple filenames or a single filehandle or blob:

($width, $height, $size, $format) = $image->Ping('logo.png');
($width, $height, $size, $format) = $image->Ping(file=>\*IMAGE);
($width, $height, $size, $format) = $image->Ping(blob=>$blob);

Poly() builds a polynomial image from an image sequence using pairs of coefficient and degree terms:

$p = $image->Poly([0.5,1.0,0.25,2.0,1.0,1.0]);

PreviewImage() tiles 9 thumbnails of an image with a processing operation applied at varying strengths to help determine optimal parameters. Supported operations: Rotate, Shear, Roll, Hue, Saturation, Brightness, Gamma, Spiff, Dull, Grayscale, Quantize, Despeckle, ReduceNoise, AddNoise, Sharpen, Blur, Threshold, EdgeDetect, Spread, Solarize, Shade, Raise, Segment, Swirl, Implode, Wave, OilPaint, CharcoalDrawing, JPEG:

$preview = $image->Preview('Gamma');
$preview->Display();

QueryFontMetrics() accepts any Annotate parameter and returns 13 font metric values for precise text layout: (1) character width, (2) character height, (3) ascender, (4) descender, (5) text width, (6) text height, (7) maximum horizontal advance, (8–11) bounding box coordinates x1, y1, x2, y2, and (12–13) origin coordinates x, y:

($x_ppem, $y_ppem, $ascender, $descender, $width, $height, $max_advance) =
  $image->QueryFontMetrics(parameters);

Use QueryMultilineFontMetrics() to obtain the maximum text width and height across multiple lines of text.

QueryColor() returns a list of all known color names when called without arguments, or returns red, green, blue, and opacity values for specified color names:

@colors = $image->QueryColor();
($red, $green, $blue) = $image->QueryColor('cyan');
($red, $green, $blue, $alpha) = $image->QueryColor('#716baeff');

QueryColorname() accepts a color specification and returns its corresponding color name or hex string:

$name = $image->QueryColorname('rgba(80,60,0,0)');

QueryFont() returns a list of all known fonts when called without arguments, or returns 11 font attributes (name, description, family, style, stretch, weight, encoding, foundry, format, metrics, and glyphs) for specified font names:

@fonts = $image->QueryFont();
$weight = ($image->QueryFont('Helvetica'))[5];

QueryFormat() returns a list of known image formats when called without arguments, or returns 7 format attributes (adjoin, blob support, raw, decoder, encoder, description, and module) for specified format names:

@formats = $image->QueryFormat();
($adjoin, $blob_support, $raw, $decoder, $encoder, $description, $module) =
  $image->QueryFormat('gif');

MagickToMime() returns the MIME type (such as image/tiff) for a given image format name (such as tif):

$mime = $image->MagickToMime('tif');

RemoteCommand() sends a filename to an already running display or animate instance:

$image->RemoteCommand('image.jpg');

Shuffle() reorders the images in an image sequence using ascending, descending, or random criteria:

$image->Shuffle('random');

Smush() joins a set of images together without gaps (or with an optional pixel offset), stacking left-to-right by default or top-to-bottom when stack is True:

$p = $image->Smush(stack=>{true,false}, offset=>integer);

Statistics() returns channel statistics—depth, minima, maxima, mean, standard deviation, kurtosis, skewness, and entropy—in RGB, CMYK, RGBA, or CMYKA order depending on image type:

@statistics = $image->Statistics();

Transform() accepts a fully-qualified geometry specification to crop or resize one or more images:

$p = $image->Transform(crop=>'100x100+0+0');

You can optionally append Image to any method name above (for example, PingImage() is an alias for Ping()).

Handling Exceptions

All PerlMagick methods return an undefined value in string context upon success. When an issue occurs, an error string containing an embedded numeric status code is returned. Status codes below 400 are warnings (indicating partial completion), whereas codes 400 or greater are fatal errors. Check exceptions according to the method's return type:

Methods returning a count (e.g., Read(), Write()):

$x = $image->Read(...);
warn "$x" if "$x";      # print the error message
$x =~ /(\d+)/;
print $1;               # print the error number
print 0+$x;             # print the number of images read

Methods operating in-place on an image (e.g., Resize(), Crop()):

$x = $image->Crop(...);
warn "$x" if "$x";      # print the error message
$x =~ /(\d+)/;
print $1;               # print the error number

Methods returning a new image object (e.g., EvaluateSequence(), Montage(), Clone()):

$x = $image->Montage(...);
warn "$x" if !ref($x);  # print the error message
$x =~ /(\d+)/;
print $1;               # print the error number

An example error message looks like:

Error 400: Memory allocation failed

You can compare extracted numeric codes directly against PerlMagick exception constants (see the complete list of error and warning codes):

$x = $image->Read('rose.png');
$x =~ /(\d+)/;
die "unable to continue" if ($1 == ResourceLimitError);
