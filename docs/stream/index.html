--- title: "Command-line Tools: Stream" description: "Stream one or more pixel components of the image or portion of the image to your choice of storage formats" topic: "CLI" ---
Example Usage Option Summary

stream is a lightweight tool to stream one or more pixel components of an image or portion of an image to your choice of storage formats. It writes pixel components as they are read from the input image a row at a time, making it ideal when working with large images or when raw pixel components are required.

Example Usage

Below are practical examples demonstrating how to use the stream command. To get started, let's stream the red, green, and blue components of a 640x480 JPEG image to disk as unsigned characters:

stream-rgb.sh 
# Stream RGB pixels to raw unsigned character data
$ magick stream -map rgb -storage-type char image.jpg pixels.dat
# Display the generated raw pixel file
$ magick display -depth 8 -size 640x480 rgb:pixels.dat

Here we extract a 100x100 region from a TIFF image in grayscale format as double-precision floating-point numbers:

stream-extract.sh 
# Extract 100x100 region with offsets X=30, Y=40
$ magick stream -map i -storage-type double -extract 100x100+30+40 image.tif gray.raw

You can also associate the region to extract directly within the input image filename:

stream-inline.sh 
# Inline geometry selection
$ magick stream -map i -storage-type double 'image.tif[100x100+30+40]' gray.raw
Format Compatibility Note: Streaming requires the image coder to read pixel data in strict row order. Not all image formats support sequential row-order reading. Always verify your specific input format before incorporating streaming into production workflows.
